## 資料與權限

- OAuth Token 只留在記憶體。裝置快取與 outbox 都以 subject + spreadsheetId 分區，不是加密保管庫；iOS 可能清除儲存，需定期備份。
- 登出／授權到期返回本機；待同步佇列保留在原帳號分區。重新登入後重新驗證檔案並接續，不把本機資料自動匯入雲端。
- 使用同一個私人試算表的兩個裝置仍有同時修改競爭風險；讀前比對不能提供跨裝置原子版本鎖。第一版單人使用，避免同時編輯同一筆。
- 健康摘要不能用 PWA CRUD 寫回原始樣本。Apps Script 只處理健康／步數，PWA 處理運動／分段／課表／影片。

## 備份範圍

本機 JSON 包含本機日摘要、運動與裝置影片庫。雲端 JSON 包含目前畫面的健康日摘要、運動（含待同步內容）與雲端影片；不包含全部原始健康樣本、SyncLogs 或完整試算表結構。完整雲端備份使用原生檔案副本，請保留私人。
