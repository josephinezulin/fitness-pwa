# 階段 D：下一輪使用體驗改善

前置：階段 C 的程式與部署已完成；iPhone 端到端情境仍依 stage-c-progress.md 驗收。接續時先查看最新回報與 GitHub 狀態，保持現有雲端與帳號隔離。

1. 跑步機範本、快走預設勾選跑步機、跑步配速及具體分段錯誤訊息。內建範本先不增加 Sheet 分頁。
2. 熱量估算使用最新且不晚於運動日的體重，可手動覆寫；機台／使用者輸入熱量不能被自動重算覆蓋。估算需標示來源與適用條件，走路／跑步式不能任意套用極低速、下坡或超出驗證條件的設定。
3. 影片「完成，記錄這次運動」預填類型、分鐘數；由使用者儲存才建立紀錄，不能將播放事件當作完成運動。
4. 每週分鐘進度、可設定目標、跑步機距離與坡度趨勢；保留原三天課表打卡。
5. 影片收藏與看過次數採裝置帳號分區；若加入雲端新分頁，必須同步修改 schema、兩支範本腳本、HealthIngest 允許列表及測試，不能臨時插入不相容表。

先前已找到的研究起點（實作前需閱讀具體內容，不憑搜尋摘要指定 MET）：

- 2024 Adult Compendium：https://pacompendium.com/adult-compendium/
- 各活動 MET 與原始更新研究：https://pmc.ncbi.nlm.nih.gov/articles/PMC10818145/
- ACSM 走路方程適用條件與驗證研究：https://pmc.ncbi.nlm.nih.gov/articles/PMC7896743/

每個可交付部分增加有意義的回歸測試，完成交接文件的檢查、CI 與部署後再更新進度。不可把估算熱量描述成實測值。
