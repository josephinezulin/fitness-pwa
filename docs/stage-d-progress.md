# 階段 D：記錄體驗與進度

## 已實作

- 快走／跑步的新表單預設啟用跑步機；既有無分段紀錄保留原本設定。影片預填的居家走路可維持非跑步機模式。
- 三組內建範本：平地健走 20 分、緩坡快走 30 分、走跑交替 30 分；一鍵帶入後可改每段。範本是可編輯的記錄起點，不是個人化運動處方，未新增 Sheet 分頁或變更合約。
- 顯示平均配速（分/km），以速度換算並處理秒數進位；分段問題說明確切段落、欄位與總時間。
- ACSM 分段及 MET 熱量輔助，體重依運動日期選用最新可用值，可手動覆寫。保留機台或使用者原有熱量，只有明確套用才填入；資料條件改變會提醒已填數字仍保留。限制與來源見 energy-estimates.md。
- 影片「完成，記錄這次運動」帶入對應類型、影片長度、名稱及網址，確認儲存才新增。播放、開啟或取消草稿不會自動建立運動。
- 收藏及觀看標記以 YouTube ID 識別，避免雲端 UI 命名空間影響紀錄。觀看次數由明確標記或儲存該次影片運動增加，同次播放先標記再記錄不會重複加次。
- 首頁改為每週累積分鐘與進度條，預設 150，可設 10–2000 分鐘。三天課表打卡仍保留；累積分鐘不等同已驗證運動強度或特定指南達標。
- 運動頁提供最近八週的分鐘、跑步機距離與時間加權平均坡度切換；跨年按週一分週，未到日期不計，沒有跑步機資料的坡度不補 0。
- 偏好以本機／Google subject + spreadsheetId 分區，清理非白名單欄位，錯誤儲存不覆蓋原文。收藏、觀看與目標留在裝置，納入 JSON 備份，舊備份仍能還原。沒有把偏好冒稱為雲端同步資料。
- 沿用 iPhone 16px 欄位字級與可縮窄網格；範本、分段欄位及影片操作保留足夠觸控高度。

## iPhone 驗收

1. 更新版本，新增快走，預設勾選跑步機；套用範本、修改其中一段，再儲存／重開確認。日期及輸入聚焦不應撐開畫面。
2. 保留一筆機台熱量，改坡度後數字不應自動變動；開啟估算、確認體重與條件，按套用才更換。舊日期不能自動引用未來體重。
3. 影片播放後按完成，檢查草稿類型／時間／教學連結；取消不新增，儲存後才打卡。先按看過再記錄，不應同次加兩次。
4. 收藏影片、只看收藏、修改週目標；切換帳號／檔案不能混用，再登入原帳號應回到裝置上原設定。
5. 匯出 JSON、修改偏好後在本機還原，收藏／觀看／目標與運動紀錄應一致。
6. 在運動頁切換三種週趨勢；無跑步機紀錄的週次不要顯示假坡度。
