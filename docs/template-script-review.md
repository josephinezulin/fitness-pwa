# Gemini 範本程式碼驗收

收到的原始碼有一個阻斷問題：WorkoutLogs.headers 缺少 deletedAt，欄數只有 10，但 textCols 包含第 11 欄；刪除多餘欄後再 getRange 到第 11 欄可能造成超出格線錯誤。即使沒有立刻報錯，產出的欄位也無法通過 PWA 契約。

另有三項修正：HealthMetrics.value 不應用整數顯示格式，避免體重體脂的小數被隱藏（格式本身不會刪除底層數值）；篩選器應包含資料列；加入欄寬、交錯底色與數值驗證。

完整替換版：[CreateFitnessTemplate.gs](../apps-script/CreateFitnessTemplate.gs)。它只建立新檔，未部署 API、未上傳任何健康資料，也不更改共用權限。重複執行會建立另一份新檔，不會修復或刪除既有半成品。

## 手動執行

1. 開啟 https://script.google.com/ ，建立新專案。
2. 將 Code.gs 原有內容完整替換為上述檔案內容。
3. 儲存，在函式下拉選單選 createFitnessTemplate，按執行。
4. 檢查 Google 授權要求：這段程式需要建立及編輯試算表。若畫面要求與此無關的存取，先停止並回報。
5. 查看執行記錄的 Google Sheets 網址。
6. 打開檔案，確認正好五張表，資料筆數 0 / 0 / 0 / 3 / 0。分享設定保持「限制存取」且無其他共用對象；實際權限仍須使用者確認，不以建立檔案動作推定私人。
7. 將網址交回驗收即可，不要公開個人資料副本，也不需按「部署」。

若已執行原版而報錯，可能已有同名半成品。先保留，確認新檔完成後再自行移除。測試檔只放預設課表，不寫真實健康數據。

程式碼的 mock 測試會檢查格線範圍、五表欄位、三筆課表、空白資料列及版本標記；它不能取代真實 Apps Script 的授權、公式驗證、格式 API 與共用權限檢查。需要使用者實際執行後提供檔案才算完成遠端驗收。
